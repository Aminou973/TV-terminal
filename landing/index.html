13 chart types

Candles to Renko to Point & Figure

Every time-based style plus the price-based charts serious traders use to cut through noise. Indicators recalculate on the bricks, just like on a pro platform.

  • Candles, hollow, Heikin Ashi, bars, columns, line, area, baseline
  • Renko, Range bars, Line break, Kagi, Point & Figure with ATR-based or fixed boxes
  • Any interval: 7m, 90m, 3h, daily, weekly, monthly — type 45 on the chart to switch
  • Session-aware dailies (CME closes at 17:00 CT, not midnight)
Multi-chart layouts

Up to four charts, perfectly in sync

Watch futures, crypto, stocks and FX side by side. Link the symbol or the crosshair across charts and save each layout to come back to.

  • 1, 2, 3 or 4 charts with independent symbol, interval and type
  • Crosshair and symbol sync across charts
  • Named layouts saved to your account, light and dark themes
  • Infinite history scroll and bar replay at up to 10×
Compare & spreads

See relative strength at a glance

Overlay any symbol as percent change, or chart a spread or ratio like ES - NQ or 2 * GC / SI straight from symbol search.

  • Regular, log, percent and indexed-to-100 scales
  • Data window with every value under the crosshair
  • Time zones, countdown to bar close, previous-close line, session breaks
86 drawing tools

Every tool, with the polish you expect

Trend lines, channels, pitchforks, Fibonacci and Gann, harmonic and Elliott patterns, long/short positions, volume profiles, anchored VWAP, shapes and notes — saved per symbol, everywhere you log in.

  • Right-click menus: settings, clone, lock, hide, z-order, alert on a line
  • Style editor with colours, widths, fills, text — and reusable style templates
  • Object tree, undo/redo, magnet, favourite-tools bar
  • Keyboard first: Alt+T trend line, Alt+F Fibonacci, Ctrl+Z undo
876 indicators + your own

Write indicators in plain JavaScript

Start from 876 built-in indicators, then build your own with OpenScript — a Pine-style API with ta.*, plot and input, running sandboxed in your browser.

  • Moving averages, oscillators, volume, volatility and 45 candlestick patterns
  • Code editor with templates, one click to add to the chart
  • Indicator templates: save a setup once, apply it to any chart
Strategy tester

Backtest before you risk a dollar

Turn an idea into a strategy with strategy.entry and strategy.close, then see exactly how it would have traded — entries and exits marked on the chart.

  • Next-bar fills, stop-loss and take-profit, commission, futures point values
  • Net profit, win rate, profit factor, drawdown, Sharpe and the full trade list
  • Equity and drawdown curves, editable inputs, up to 20,000 bars
Paper trading & NinjaTrader 8

Practice on live data, then route to NT8

Paper trade on the live feed with market, limit and stop orders — positions and working orders drawn right on the chart. When you're ready, route orders to your NinjaTrader 8 account.

  • Order book and time & sales with buy/sell aggressor colouring
  • Real P&L with futures point values (ES $50, NQ $20 …)
  • Server-side alerts on price, trend lines, indicators and script signals
  • Webhook, Telegram and email delivery with message placeholders
  • NinjaTrader routing is opt-in, admin-only and allow-listed per account

Get started

Up and running in five minutes

No NinjaTrader needed to try it — a built-in simulator streams live ticks, and a seeding script adds a month of demo history.

Docker — one command
$ git clone https://github.com/Aminou973/TV-terminal
$ cd TV-terminal
$ cp server/.env.example server/.env
$ docker compose up --build
# open http://localhost:8000 → Register
Dev — Python 3.12+ & Node 18+
$ cd server && pip install -e ".[dev]"
$ python scripts/seed_demo.py
$ uvicorn app.main:app --port 8000
$ cd ../web && npm install && npm run dev
# open http://localhost:5173 → Register
