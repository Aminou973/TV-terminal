Features

A real trading terminal, running on your own box

Everything you need to chart live markets privately — built on open components you can read, fork and extend.

Professional charts

Powered by TradingView's open-source Lightweight Charts v5 — the same fast canvas engine, with a familiar dark theme.

NinjaTrader 8 bridge

A dependency-free NinjaScript AddOn streams your CME futures ticks over localhost NDJSON. NT8 stability comes first.

Live crypto via ccxt

Public Binance market data out of the box — 1m history backfill plus a live trade stream. No API key required.

Parquet storage

Every closed 1m bar lands in a per-symbol, per-day Parquet file. Analytical-friendly, portable, and yours.

History = live, structurally

One 1m base, one resampler. REST history and WebSocket bars use identical bucketing, so the right edge never drifts.

Multi-user, self-hosted

JWT auth with bcrypt passwords and SQLite. Share one instance across your LAN or desk — nothing leaves your network.

Architecture

Ticks in, candles out

Providers feed one candle engine. The server does all the timeframe math, so every client sees the same bars.

Quick start

Live chart in two terminals

No NinjaTrader needed to try it — the built-in simulator streams synthetic ES ticks and BTC flows from Binance.

backend · Python 3.12+
$ cd server
$ python -m venv .venv
$ .venv/bin/pip install -e ".[dev]"
$ .venv/bin/uvicorn app.main:app --port 8000
# serving on http://localhost:8000
frontend · Node 18+
$ cd web
$ npm install
$ npm run dev
# open http://localhost:5173
# register an account → terminal opens
